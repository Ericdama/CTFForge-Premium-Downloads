# CTFForge Premium

A desktop application project focused on Capture the Flag (CTF) practice and cybersecurity learning.

## About

CTFForge Premium is being developed for students, beginners, and cybersecurity enthusiasts who want to explore CTF challenges.

**Version:** 1.0.0  
**Platform:** Windows  
**Developer:** Eric Dama

## Download

Download the Windows installer from the **Releases** section of this repository.

> The initial release is version 1.0.0. Please report any installation problems or bugs through GitHub Issues.

## Installation

1. Open the latest release.
2. Download the CTFForge Premium Windows installer.
3. Run the installer and follow the setup instructions.
4. Launch CTFForge Premium from the Start Menu or desktop shortcut.

Only install releases downloaded from the official project repository.
